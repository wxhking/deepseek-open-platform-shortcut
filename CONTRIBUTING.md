# Contributing

Thanks for considering a contribution.

1. Keep the extension limited to `https://chat.deepseek.com/*` unless a scope change is discussed first.
2. Do not add analytics, remote code, or permissions that are not needed for the shortcut.
3. Keep the extension installable as an unpacked Manifest V3 extension with no build step.
4. Before opening a pull request, validate `manifest.json`, run `node --check content.js`, and manually verify the menu and navigation in Chrome.
5. Describe the behavior you changed and include screenshots for UI changes.

By submitting a contribution, you agree that it may be distributed under this repository's MIT License.
